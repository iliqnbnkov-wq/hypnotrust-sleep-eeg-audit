# Model Card Summary

## Intended use

Educational and research demonstration of uncertainty-aware review prioritization for sleep-stage predictions.

## Not intended use

Clinical diagnosis, real medical deployment, replacement of sleep specialists or automated final scoring.

## Key risks

- subject-specific variability
- N2-attractor behavior
- reduced reliability around difficult transitions
- possible mismatch between confidence and correctness

## Recommended interpretation

Use the dashboard as an audit and review-prioritization tool, not as a clinical decision system.
