# Project Positioning

Automatic sleep staging is an established research area. HypnoTrust does not claim that sleep-stage classification itself is new.

The contribution of this project is the construction of a small, reproducible trust and audit workflow around sleep-stage predictions:

- locked evaluation framing
- uncertainty-based review prioritization
- calibration-oriented analysis
- failure-mode inspection
- subject-level comparison
- Streamlit dashboard for explanation and review

The goal is not to replace a specialist, but to show where a model should be trusted less and where human review should be prioritized.
